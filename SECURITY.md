# Security policy

flutterkill deletes files, so a bug that removes something outside the rules in the README's [safety model](README.md#safety-model) is a security issue.

## Reporting

Please report privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Include the flutterkill version, OS, and steps to reproduce using placeholder paths. You can expect an acknowledgement within a week.

## Supported versions

Only the latest release receives fixes.
